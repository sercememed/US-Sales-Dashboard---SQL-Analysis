# US-Sales-Dashboard---SQL-Analysis
SQL analysis for Tableau Sales Dashboard project

Project Overview

This project analyzes US sales data using SQL for data processing and Tableau for interactive dashboard creation.

The main goal is to transform raw sales data into actionable business insights that support decision-making in areas such as revenue optimization, product performance, and regional sales analysis.


Business Problem

Companies often struggle with:

* Identifying their most profitable products
* Understanding regional sales performance
* Tracking revenue trends over time
* Making data-driven inventory and marketing decisions

This project addresses these issues by building a structured analytical pipeline.


The dataset is based on a retail sales structure including:

* Sales transactions
* Product details
* Customer information
* Geographic regions
* Time-based sales data


* SQL (Data Cleaning & Transformation)
* Tableau (Data Visualization & Dashboard)
* Excel (Initial data inspection)


Data Processing (SQL Layer)

Key transformations:

* Cleaned raw transactional data
* Built relationships between fact and dimension tables
* Aggregated sales metrics (Revenue, Quantity, Profit)
* Joined customer, product, and region data for analysis


Dashboard Structure

The Power BI dashboard contains:

1. Executive Overview

* Total Revenue
* Total Orders
* Total Profit
* Average Order Value

2. Product Analysis

* Top-performing products
* Revenue contribution per product
* Product category comparison

3. Regional Analysis

* Sales by region/state
* High vs low performing areas

4. Time Series Analysis

* Monthly/quarterly revenue trends
* Seasonality patterns


Key Insights

* A small group of products contributes a large portion of total revenue (Pareto effect)
* Certain regions consistently underperform compared to others
* Sales show seasonal peaks in specific periods
* Profit margins vary significantly across product categories



Conclusion

This project demonstrates how SQL and Power BI can be combined to convert raw data into business insights that support strategic decisions.


Future Improvements

* Add predictive sales forecasting
* Implement customer segmentation (RFM analysis)
* Automate data pipeline using Python
* Add real-time dashboard updates
