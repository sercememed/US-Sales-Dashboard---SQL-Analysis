# US-Sales-Dashboard---SQL-Analysis
SQL analysis for Tableau Sales Dashboard project


Upper Intermediate SQL Analysis

This project includes Upper Intermediate SQL techniques:

- CTE (Common Table Expressions)

- Window Functions (RANK, LAG)

- Running totals and ranking logic

- Regional performance comparison

These queries simulate real-world business analysis scenarios.
